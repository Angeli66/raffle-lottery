# RaffleLottery – Decentralized Ticket-Based Prize Draws

RaffleLottery enables transparent lottery participation by allowing users to buy tickets and automatically enter periodic prize draws executed on-chain.

## Core Capabilities
- Ticket purchase with unlimited entries
- Randomized winner selection system
- Prize pool funded by ticket sales
- Winner verification and claim settlement

## Key Functions
buy-ticket, draw-winner, claim-prize, get-ticket-count, get-prize-pool
